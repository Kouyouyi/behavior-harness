# BEHAVIOR 主动感知 Harness：代码与 OOD 仿真交接

2026-10-20 的独立代码快照。**仿真和 planner 在本地 GPU 主机；huoshan 仅运行 VLA 推理和下载。** 仓库没有启动任何任务，原工作目录中的批测仍独立运行。

## 从哪里开始

1. 阅读 [交接与部署](docs/HANDOFF.md)，按环境清单安装官方仿真及获授权资产。
2. 阅读 [OOD 场景与验收](docs/OOD.md)，确认目标、支持关系、种子和成功条件。
3. 按 `scripts/configure_handoff_paths.py --help` 修改此副本中的机器路径；检查修改，再执行单元测试。
4. 先运行单场景 `--initialize-only --initial-visibility-audit`，再进行闭环。不要直接启动全量评测。

## 内容

- `ap_harness/`：场景设置、planner/VLA 调度、严格验收、完整状态交接、动作 ACK。
- `runtime/`：本地 BEHAVIOR 后端、视觉 planner、相机和视频记录。
- `configs/ood99/`：99 个任务候选 OOD 的完整配置；不是 99 个已验收成功场景。
- `configs/champion_search_suite/manifest.json`：当前筛选结果，39 可比较、18 容器示范未确认暂排除、42 冠军任务表不支持。
- `pi05_harness_20261017/`：AP 推理接口、R1Pro 配置、训练契约、归一化元数据和配套代码；不含 checkpoint 权重。
- `remote/`：当前远端冠军服务、启动/重置/下载代码和协议测试。
- `environment/`：本地环境导出、远端依赖清单、仿真/冠军固定版本及修改补丁。
- `docs/result_snapshots/`：交接时结果摘要快照；不是实时状态，视频不包含在 Git 中。
- `docs/LEGACY_NOTES.md`：历史排查笔记，旧版本预算/超时设置不能覆盖当前代码。

## 当前实验口径

两组同场景、同种子、从初始状态开始，各 10,000 步总预算：冠军直接执行；或 AP checkpoint_024000 搜索最多 800 步，再交给对应冠军权重执行剩余预算。搜索到达与官方 BDDL 原任务成功分别统计。冠军采用发布方 50 任务固定编号和 4 checkpoint 映射，不能拿收音机编号运行其他任务。

训练标签存在不等于策略掌握技能。当前 18 个容器场景是因未核实对应开容器示范保守排除，不是已证明训练数据没有开容器动作。

## 交付边界

这是可交接的源码、场景构造和环境复现仓库，**不是含全部 Isaac/BEHAVIOR 资产和模型权重的自包含安装包**。资产、授权密钥、训练数据、模型权重、认证信息和运行视频未纳入 Git；接收方需自行获取许可并配置。尚未在全新机器完整安装验证。

第三方代码保留原有版权/许可证。本项目快照不额外授予官方资产、模型或第三方代码的再分发许可；不要直接公开上传未经核查的第三方文件。
