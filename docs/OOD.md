# OOD 配置与仿真边界

`configs/ood99/*.json` 包含 task_name、instance_id=301、seed、target_keys、placements、目标原始支撑/容纳关系和验收。程序通过官方对象状态采样器在原支持物体上重放置，水平位移至少0.08m。保持原有物体属性和关系。若原有inside祖先可开合则在初始化关闭，之后将机器人初始朝向调整为背离目标。新批39任务保守排除这18个inside候选。

这些是规则生成的布局/朝向扰动，不证明与训练分布统计不重叠。不是离线改了一张图片：仿真加载真实资产后修改实体状态，并复查关系。没有独立三角网格穿透深度验证。

初始预检：所有同类目标在三机载相机中均不可见；检查关系及初始状态fingerprint。闭环目标：planner reached，**同一个**目标实际渲染>=16像素且水平距离<=1.0m。终端可见性审计后不可继续物理。交接前保存完整状态，在干净仿真恢复休眠标志及派生缓存，严格全状态检查，新增物理步数为0。

容器关节和目标位姿只允许初始化修改，不能当策略动作。运行中只执行模型动作前缀并记录submitted/ack。等待模型时物理冻结；出现未确认动作不得重放部分轨迹。基础设施/无效场景必须与能力失败分开，修复后从新目录和初始场景重测。

官方原任务成功由环境BDDL判断，找到/靠近目标不等于完成抓取、放置或开机。
