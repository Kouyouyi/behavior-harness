## 下一步顺序

当前执行顺序更新为：提取示范中的迈步参考 → 隔离仿真验证真实抬脚、前移与停步 → 实机验证短距离走近/停稳 → RGB-D 重新观察站位与玩偶 → 伸手、闭合、抬起验证。不能把速度乘时长、参考 root 平移或参考幅度当作实际位移。靠近桌面的下降/横移被自动审批拒绝后，已改用向上后撤并停机；不重试被拒绝的动作。

1. E024–E026 一轮真机已完成并正常停机。单肘旧判据保持；新 `clear_reach_v1` 是有独立软件验证、现场证据和验收标准的动作协议，不重写 E008 失败记录。
2. 不把消除 SONIC 跟踪误差、或完成独立的多次精确回位测试，作为推进抓取的硬性前置条件。2 cm 回位门槛是本次接入选择的粗调试判据，不是 RAX 原有 skill 要求，也不是所有操作任务的统一容差。E026 的 2.70 cm 目标误差、1.94 cm 回位误差按原标准保留记录。
3. 下一步建立物体位置与实际手部/抓取点之间可靠的对应关系，核对相机外参、BrainCo 安装和抓取点，并接入手部命令/握持反馈。当前工具不能输出已标定的机身物体位置；这一缺项不同于 SONIC 的残余跟踪误差。
4. 在原地玩偶任务中用“观察实际状态 → 接近 → 再观察 → 必要时小步修正 → 抓取确认”验证闭环。按物品尺寸、接近间隙和抓取方式设容差；只有残余误差实际妨碍任务时才针对性补偿，不要求低层参考精确跟踪。重复性和误差记录随任务验证积累，家庭搬运仍需后续分项验收。
5. E025 现场已确认本轮离髋后无接触，但没有测得实际厘米间隙，头部相机也看不到该处。保留原生回读、失联/姿态/速度保护、原生 O 和失败后不自动重试。当前执行器参数未因本次解释修正而改变，新任务应使用明确的任务判据。
